# スタッフクレジット（クリア後）

ステージ10をクリア → ED（`resources/cutscene/ending.tres`）→ **クレジット** の順に出る。
1画面に1人ずつ、順に出して消す。流れる（スクロールする）形ではない。

出せる場所は2つ。中身（`resources/credits.tres`）はどちらも同じものを見ている。

| 場所 | |
| --- | --- |
| クリア後 | ED のあとに自動で。`Main.tscn` の Game → `credits` に割り当て |
| タイトル画面 | メニューの **CREDITS**。遊ばなくてもいつでも見られる |

タイトルの CREDITS はその場で流すだけで、画面は移らない。流している間はツリーを
止めているので、裏のメニューは触れない。終わると元のメニューに戻る

## 中身を直す

`resources/credits.tres`（CreditsData）。Godot のインスペクタで開くと配列で並ぶ。

| 項目 | 意味 |
| --- | --- |
| `entries` | 出す順。**1件が1画面** |
| `entries/role` | 名前の上に小さく出す肩書き |
| `entries/person` | 中央に大きく出す名前 |
| `entries/hold` | その画面だけ表示時間を変えたいとき（0 なら下の既定） |
| `background` | 背景。null なら黒一色 |
| `bgm` | 流す曲。null なら無音 |
| `hold` / `fade` | 1画面を出しておく秒数 / 文字の出入りの秒数 |
| `open_fade` / `bgm_fade` | 始めと終わりの明転暗転 / 曲を消す秒数 |
| `closing` / `closing_hold` | 最後の締めの一行とその秒数 |

同じ役割に複数人いるときは、その人数ぶん `entries` を並べる（ボイスやプレイテスト）。

## 雪（冬の公開）

クレジットの画面に雪を降らせている。`resources/shader/snow.gdshader` を全画面の
ColorRect に貼り、背景と一緒に明転・暗転する。背景の上・**文字の下**に敷いてあるので、
名前の読みやすさは今までと変わらない。

| 項目（`credits.tres`） | 既定 | |
| --- | --- | --- |
| `snow` | on | 切ると今までの画面に戻る |
| `snow_amount` | 1.0 | 粒の多さ |
| `snow_speed` | 1.0 | 落ちる速さ。1.0 で手前の粒が画面を約5.5秒で通る |
| `snow_size` | 1.0 | 粒の大きさ |
| `snow_color` | 白（a=0.85） | アルファで薄さが決まる |

奥行きは3層で、手前ほど大きく・速く・濃い。横へ少し流れる（`wind`）のと、
1粒ごとの横揺れ（`sway`）はシェーダー側の既定値。変えたいときは
`snow.gdshader` の uniform を直す（全部の層に効く）。

降りかたは一定ではなく、ゆっくりした波で**量と動きが増減する**。

| uniform（`snow.gdshader`） | 既定 | |
| --- | --- | --- |
| `breath_speed` | 0.3 | 波の速さ。約21秒で一巡 |
| `breath_amount` | 0.35 | 量の振れ幅。±35% |
| `breath_motion` | 0.35 | 落ちる速さと風の振れ幅。±35% |

層ごとに波の位相をずらしてあるので、画面全体が同時に強まったり弱まったりはしない。
速さは「速さ」ではなく**進んだ距離**の側で揺らしている（`travelled()`）。速さに直接
sin を掛けると、波が変わった瞬間に粒が飛ぶため。量のほうも、境目の粒は薄く出して
点いたり消えたりしないようにしている。

粒の大きさも落ちる速さも画面の高さに対する割合で持っているので、
解像度を変えても見え方は変わらない。縦横比だけは `credits.gd` が渡している
（渡さないと粒が横に伸びる）。

**冬が終わったら `credits.tres` の `snow` を外す。** それだけでよい。

## 確認のしかた

タイトルの **CREDITS**、またはゲーム中に **F6 → `▶ CREDITS`** で、クレジットだけ流せる
（ステージ10まで行かなくてよい）。

機械的な確認:

```
godot --headless --path . --script res://tools/check_credits.gd
```

中身の並び・`Main.tscn` への割り当て・タイトルの CREDITS ボタン（実際に押して、
始まって止まって戻るところまで）・通しの再生順を見る。

中身が空でないか、`Main.tscn` の Game に割り当てられているか、
実際に流して**並び順どおりに1人ずつ出るか**を見る。

見た目を1枚撮る（目視確認用）:

```
godot --path . --script res://tools/shot_credits.gd -- out.png 2.0
```

## 作り

| ファイル | |
| --- | --- |
| `scripts/credits_data.gd` | 中身（`CreditsData`）。並びと背景と曲と尺 |
| `scripts/credit_entry.gd` | 1画面ぶん（`CreditEntry`）。役割と名前 |
| `scripts/credits.gd` | 出し方（`Credits`）。CanvasLayer を実行時に組み立てる |
| `scripts/game.gd` | `credits` を持ち、ED のあと `play_credits()` を呼ぶ |

中身を .tres に置き、画面の組み立てはスクリプトが持つ——イベント（Cutscene / CutsceneData）と
同じ作りにしてある。人を1人足すのにシーンを開かなくてよい。

再生中はツリー全体を止め、このノードだけ `PROCESS_MODE_ALWAYS` で動かす。これもイベントと同じ。
