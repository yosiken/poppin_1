# ポゴ系 面クリアアクション 仕様書 v0.2

- エンジン: Godot 4.x / PCスタンドアロン（Windows想定）
- ジャンル: 物理跳躍アクション（面クリア型）
- 判定: 2D（横視点）
- 表示: ステージ画像（ビットマップ）＋ ポリゴンコリジョン

---

## 1. コアループ

```
面に入る → 跳んで登る → 落ちる（軽い復帰）→ 収集アイテムを取る
→ ゴール → スキル解放 → 前の面の届かなかった場所に戻れる
```

「落下ペナルティが軽い」ため、難度の主軸は **恐怖 → 精度と反復** に移る。
その分、収集アイテムを危険な位置に置くことで緊張を作る。

## 2. プレイヤー操作

### 入力（キーボード基準／パッドも同マッピングで対応）

| 入力 | 動作 |
|---|---|
| ← / → | ポゴの傾き角θを左右に回す（角速度制御） |
| Space（保持） | チャージ。離すか着地でリリース |
| R | 手動リトライ（直近チェック地点） |
| Esc | ポーズ／スキルツリー |

### 傾き制御
- θ は目標角ではなく**角速度で回す**。`θ += tilt_input * TILT_SPEED * dt`
- キーを離すと `STABILIZE_RATE` で 0° に戻る（安定性スキルで上昇）
- 可動域: ±60°（初期）

### 反発（接地の瞬間のみ発生）
```
n      = 接触面の法線
v_in   = 接触直前の速度
base   = reflect(v_in, n) * RESTITUTION
dir    = θ から作った射出方向ベクトル
v_out  = lerp(base, dir * |base|, POGO_AUTHORITY) + n * BOUNCE_ADD
```
- `POGO_AUTHORITY = 0.75`（プレイヤー意志が7.5割、地形反射が2.5割）
- `BOUNCE_ADD` は最低跳躍量。これがないと平地で死ぬ

### チャージ
- 接地の**前**に押していれば有効（先行入力を許可）
- 蓄積 0〜1.0（満タン 0.6秒）→ `BOUNCE_ADD` と `RESTITUTION` を最大 1.5倍
- 満タン時のみ画面端に微発光（音でも通知）

### 転倒（ダウン） — 廃止
- v0.3 でこの判定自体を削除。着地はθに関わらず常にバウンドする
- 理由: 転倒→復帰待ちが操作感を損なうためゲームとして不要と判断

## 3. ストレス低減補正

| 補正 | 内容 |
|---|---|
| 入力バッファ | 接地の8フレーム前までの入力を接地時に適用 |
| 着地スナップ | 目標角との差が±5°以内なら自動吸着 |
| エッジアシスト | 縁を6px以内で掠めた場合、接地扱いに寄せる |
| 壁反発減衰 | 壁面（法線が水平寄り）は反発0.4倍。無限バウンド事故を防止 |
| 天井処理 | 天井接触は反発せず速度を殺すのみ |
| カメラ先読み | 上昇中はデッドゾーンを下げ、上方を多く映す |
| コヨーテ角 | 接地判定と同時にθを1フレーム保持し、判定の揺れを吸収 |

## 4. 落下と復帰

「落下地点付近に即復帰」を採用。ただし完全無痛にはしない。

- ステージには **リカバリーポイント**（不可視、地形上に自動配置または手置き）を持つ
- 落下判定 = 「連続下降距離 > FALL_THRESHOLD（初期900px）」かつ着地
- 復帰先: 落下開始地点から**下に1段だけ**戻ったリカバリーポイント
- 復帰演出 0.5秒（フェード＋SE）。これが実質的なペナルティ
- 落下カウンタを面ごとに記録（スコア表示用、成長要素には非連動）

### リトライスキル
- 「リトライ」系スキルは **チェックポイント設置権**：
  - Lv1: 面内に任意で1回セーブ地点を打てる
  - Lv2: 2回
  - Lv3: 復帰演出短縮（0.5s → 0.15s）
- 落下復帰が軽い設計なので、リトライスキルは「登り直しの手間削減」に振る

## 5. スキルツリー

### ポイント入手
**ステージ内の収集アイテム（Cog）のみ**。
- 1面あたり 4〜6個
- 配置ルール:
  - 1〜2個: 通常ルート上（誰でも取れる）
  - 2〜3個: 現在のスキルでは届かない位置（再訪前提）
  - 1個: 明確に危険な位置（落下確定ルートの先端）
- 取得は永続。落下しても取得済みは維持

### ツリー構成（低コスト多段・分岐なし推奨）

| 系統 | Lv1 | Lv2 | Lv3 |
|---|---|---|---|
| ジャンプ力 | BOUNCE_ADD +8% | +16% | +25% |
| 安定性 | 復元速度 +30% | +60% | 可動域 ±75° |
| スーパージャンプ | 満タンチャージで1.8倍（CT 6秒） | CT 3秒 | 空中で1回だけ発動可 |
| リトライ | チェック地点1回 | 2回 | 復帰演出短縮 |

コストは 2 / 3 / 5 Cog。全解放に約 40 Cog ＝ 8面分。

## 6. ステージ

- 1面サイズ: 3840 x 2160（1080p換算で2x2画面）
- 面数: 初期リリース 8面（+ チュートリアル1）
- 目標クリア時間: 初見 3〜6分 / 熟練 40秒〜

### シーン構成
```
Stage.tscn
├── ParallaxBackground/  (Sprite2D 背景レイヤー ×2)
├── StageArt             (Sprite2D  地形の見た目)
├── Terrain (StaticBody2D)
│   └── CollisionPolygon2D × N   ← 見た目とは別データ
├── RecoveryPoints (Node2D)      ← Marker2D × N
├── Collectibles   (Node2D)      ← Cog.tscn × 4〜6
├── Goal (Area2D)
└── StageBounds (Area2D)         ← 場外落下の保険
```

### コリジョン制作パイプライン
1. ステージ画像を作る（PNG, 3840x2160）
2. 外部ツールでポリゴン輪郭を作成（Blender / Inkscape / 自作エディタ）
3. 頂点配列を JSON でエクスポート
4. Godot 側 `@tool` スクリプトで `CollisionPolygon2D` を生成
   - 1ポリゴンあたり頂点は 200 以下に分割
   - 凹形状は Godot が自動で凸分割するが、極端な形状は手動分割
5. デバッグ表示（F1でコリジョンのみ表示）を必ず用意

## 7. データ設計（Godot Resource）

```gdscript
# PogoStats.tres  — 物理パラメータの実体
class_name PogoStats extends Resource
@export var restitution      := 0.62
@export var bounce_add       := 380.0   # px/s
@export var pogo_authority   := 0.75
@export var tilt_speed       := 180.0   # deg/s
@export var stabilize_rate   := 120.0   # deg/s
@export var tilt_limit       := 60.0    # deg
@export var gravity          := 1800.0
@export var charge_time      := 0.6
@export var charge_mult      := 1.5

# SkillData.tres — 1スキルの定義
class_name SkillData extends Resource
@export var id: StringName
@export var levels: Array[Dictionary]   # {cost, mods:{param:value}}
```

- スキル効果は `PogoStats` への加算/乗算モディファイア群として適用
- セーブは `user://save.json`（解放スキル、取得Cog ID、面クリア状況、ベストタイム）
