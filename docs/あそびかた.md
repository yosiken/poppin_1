# あそびかた

『泥酔配信者の異世界転生記 ～失われた記憶と10個の大好物～』

はじめて遊ぶ人向けの説明です。読まなくても遊べますが、
**このゲームは「歩く」ことができません。** そこだけ先に知っておくと楽です。

---

## どんなゲーム？

深酒した配信者のOBが、目を覚ますと異世界にいました。
帰るには、失くした**10個の記憶（＝大好物）**を取り戻さなければいけません。

相棒のカニエナガと一緒に、ホッピング（ポゴスティック）で
10のステージを跳んで登っていきます。

---

## 操作

| | キーボード | ゲームパッド |
|---|---|---|
| **傾ける**（跳ぶ向きを決める） | `A` / `D` または `←` / `→` | 十字キー左右 / 左スティック |
| **ためる**（大きく跳ぶ） | `Space` | A（下ボタン） |
| ステージをやり直す | `R` | セレクト |
| メニューを開く | `Esc` | — |

会話の場面では

| | |
|---|---|
| 次へ進める | `Space` / クリック |
| 会話を飛ばす | `Enter` |

## 跳びかたの基本

### 1. 放っておいても跳ねます

地面に着くたびに自動で跳ね返ります。ジャンプボタンを押す必要はありません。
**跳ぶのを止めることはできません。**

### 2. 左右キーは「移動」ではなく「傾き」

`A` / `D` を押すと、ホッピングが**その方向へ傾きます**。
押している間じわじわ傾き、離すと自動で真上へ戻ります。

跳ね返る向きは、**着地した瞬間の傾き**で決まります。

```
まっすぐ   → その場で小さく跳ねる
右に傾ける → 右へ跳ぶ
```

つまり「右へ進みたいから右を押す」のではなく、
**「着地の瞬間に右へ傾いていたいから、その前に右を押しておく」**のが正しい感覚です。
慣れるまでは、ここが一番とまどうところだと思います。

### 3. 傾けすぎは戻せません

傾けられるのは左右それぞれ 35 度までです。
倒しすぎると横へ飛びすぎて、戻ってこられなくなります。
**小さく傾けて小さく進む**ほうが、結果的に速く登れます。

### 4. 坂では向きが引っぱられます

坂に着地すると、跳ね返る向きが坂の傾きに引っぱられます。
急な坂ほど横へ流されるので、坂に入る前に向きを整えておきましょう。

### 5. `Space` でためる

地面に着いているときに `Space` を押し続けると、その場で**踏みとどまって力をためます**。
止まっていられるのは一瞬だけで、ためきると自動的に発射されます。

ためて跳ぶと、普通の跳ね返りより**大きく跳べます**。
高いところへ登るときや、遠くへ渡るときに使います。

> **コツ** … 止まっている間も傾きは変えられます。
> 「止まる → 向きを決める → 飛ぶ」の順で考えると狙いやすくなります。
>
> ためは**空中で押し始めても進みます**。着地する前から押しておけば、
> 着地と同時にためた状態にできます。
> 離すのが少し早すぎても、着地まで覚えているので無駄になりません。

## ステージの進めかた

### ゴール

各ステージの一番奥（たいてい一番高いところ）に**大好物**が置いてあります。
触れるとそのステージはクリアです。

### 落ちてもだいじけん

ステージの下まで落ちたり、**赤い床**に触れたりすると、
**少し手前の地点からやり直し**になります。
（赤い床は触れると落ちる床です。緑の足場・茶色の壁と色で区別してあります）

- 残機はありません。**何度落ちても終わりになりません**
- 一度通った復帰地点は巻き戻りません。進んだぶんは必ず残ります
- 落ちると少しだけ時間を取られます。記録に残るのは**タイムと落下回数**だけです

高いところで「落ちたら終わり」と怖がる必要はありません。
思い切って跳んだほうが早く進めます。

### やり直したいとき

`R` を押すと、そのステージを最初からやり直せます。タイムもリセットされます。
ベストタイムを狙うときに使ってください。

### クリアすると

- **TIME**（かかった秒数）と **FALLS**（落ちた回数）が表示されます
- 取り戻した記憶が並ぶ画面が出ます（**○/10**）
- 会話をはさんで、次のステージへ進みます

セーブはここで自動的に行われます。

---

## 1ステージの流れ

```
会話（Space で送り、Enter で飛ばせます）
  ↓
プレイ（跳んでゴールの大好物まで）
  ↓
クリア表示（TIME と FALLS）
  ↓
記憶コレクション（○/10）
  ↓
会話 → 次のステージへ
```

全10ステージ。10個そろえば、OBは元の世界へ帰れます。

## タイトル画面

| | |
|---|---|
| **NEW GAME** | 最初から始めます。セーブがある場合は確認が出ます |
| **CONTINUE** | 続きから始めます。セーブがあるときだけ選べます |
| **OPTIONS** | BGM・効果音の音量、プレイヤー名を変えられます |
| **RANKING** | オンラインの記録を見られます |

### ランキングについて

ステージごとのタイムと、全10ステージの合計タイムが記録されます。
名前は OPTIONS で変えられます。

上位の記録には**リプレイ**が付いていることがあります。
ランキング画面から再生すると、その人の動きをそのまま見られます。
登りかたに詰まったときの参考になります。

### ゲーム中のメニュー（`Esc`）

| | |
|---|---|
| **RESUME** | ゲームに戻ります |
| **SAVE** | 今のステージの頭からとして保存します |
| **RETURN TO TITLE** | タイトルに戻ります |
| **QUIT GAME** | ゲームを終了します |

## つまずいたら

**まっすぐ跳ぶばかりで進まない**
→ 着地の瞬間に傾いている必要があります。
跳んでいる最中に、次の着地にそなえて傾けておきましょう。

**横に飛びすぎて落ちる**
→ 傾けすぎです。キーは「押しっぱなし」ではなく「軽く叩く」感覚で。
離せば自動で真上に戻ります。

**高いところに届かない**
→ `Space` でためてから跳んでください。
勢いがついている状態でためると、さらに高く跳べます。

**同じところで何度も落ちる**
→ 落ちても進んだぶんは残ります。回数を気にせず試してください。
どうしても抜けられなければ、ランキングのリプレイで登りかたを見るのも手です。
