# ボイスリスト案

OB（および一部カニエナガ）の短いボイスを、プレイ中とイベントに入れるための案。

> **この案の範囲**
> ここで扱うのは「掛け声・リアクション」の**システムボイス**だけです。
> 台本のセリフ全部に声を当てる**フルボイス**は、本数が二桁変わる（v4台本で 500 行超）
> 別の判断になるので、ここには含めていません。
>
> 現状、会話中に鳴っているのは `voice.mp3` を話者ごとにピッチを変えて鳴らしている
> 「しゃべっているふうの音」で、実際の声ではありません（`Cutscene._speak()`）。

---

## 設計の前提

### 1. 鳴る頻度で優先度が決まる

このゲームは**地面に着くたび自動で跳ねます**。バウンドは1ステージで数百回起きるので、
そこに声を入れると確実に飽きます。**声は「めったに起きないこと」に付けるのが原則**です。

| 頻度 | 例 | 声を入れるか |
|---|---|---|
| 毎秒 | バウンド、着地 | **入れない**（今の効果音のまま） |
| 数秒に1回 | ためジャンプ | **確率で**鳴らす（20〜30%） |
| 数十秒に1回 | 落下、復帰、壁ずり | 入れる |
| ステージに数回 | 復帰地点、ゴール | 入れる |
| ゲームに1回 | 記憶取得、全クリア | 入れる（ここは贅沢に） |

### 2. 同じ声を連続で鳴らさない

同カテゴリ内はランダム選択。**直前に鳴ったものは次に選ばない**こと。
2本しかないと交互に聞こえて逆に目立つので、**最低3本**から。

### 3. 声同士を重ねない

1本のプレイヤーで鳴らし、再生中の要求は捨てるか上書きする。
効果音（着地音など）とは別プレイヤーにして、効果音は普通に重ねます。

### 4. 音量を別に出す

今の OPTIONS は BGM と SE の2つだけです。**ボイスは独立したバス**にして
スライダーを足すのをおすすめします（`default_bus_layout.tres` に `VOICE` を追加）。
「声だけ切りたい」「声だけ上げたい」は実況者向けタイトルでは要望が出やすい項目です。

## 収録の実務

### ファイル名と置き場

```
resources/sound/voice/
  ob_jump_01.mp3 〜 ob_jump_06.mp3
  ob_fall_01.mp3 〜 ob_fall_05.mp3
  ...
  kani_fall_01.mp3 〜
```

連番は**ゼロ詰め2桁**。コードは「接頭辞で始まるファイルを全部読んでランダムに選ぶ」
作りにすれば、**本数を増やすときにコードを触らずに済みます**（背景やポップアップの
読み込みと同じやり方です）。

### 収録時の注意

- **頭の無音を詰める**こと。`voice.mp3` は先頭 0.10 秒が無音で、そのままでは
  遅れて聞こえるため `voice_start` で飛ばしています。同じ手当てを増やしたくありません
- 尺は**0.5〜1.5 秒**。ゴールと全クリアだけは 2 秒まで
- 落下の声は**短く**。復帰演出が 0.5 秒なので、それより長いと次の場面に食い込みます
- テンションは「配信中のノリ」。素面のときより一段高め、ただし酔ってはいない
  （酔っているのは OP だけです）

| | 本数 |
|---|---|
| A. プレイ中（最小構成） | 27 |
| B. 演出の節目 | 10 |
| C. カニエナガ | 9 |
| **合計** | **46** |

A だけで 27 本。まず A を録って入れてみて、物足りないところに B・C を足す進め方を
おすすめします。

## 実装側で先に要るもの

ボイスを入れる前に、コード側でこの3つが必要です。

1. **ボイス再生の共通化** — 接頭辞でまとめて読み、直前と同じものを選ばず、
   再生中は重ねない。`Cutscene._speak()` の最短間隔の考え方がそのまま流用できます
2. **`VOICE` バスと OPTIONS のスライダー** — `default_bus_layout.tres` と
   `scripts/settings.gd` / `scripts/title.gd`
3. **復帰地点のシグナル** — `Game._update_checkpoint()` は今 `print` だけで、
   外から拾えません

どれも小さいので、収録前にこちらで用意できます。

## 届いたボイスの下処理（2026-11-25）

届いた65本（`resources/sound/OB_voice/*.wav`）を、ゲームで使う形に整えて
`resources/sound/voice/*.ogg` に書き出した。ファイル名は元のまま（拡張子だけ .ogg）。
やり直すときは次を流す（元の wav には手を付けない。何度流しても同じ）。

```
python tools/process_voice.py
```

| | 届いたまま | 整えたあと |
| --- | --- | --- |
| 形式 | wav 48kHz ステレオ 16bit | Ogg Vorbis 48kHz モノラル（品質5） |
| 容量 | 33.8 MB | 1.46 MB |
| 頭の無音 | 0.06〜1.13 秒 | 0.03 秒 |
| 長さ | 1.09〜14.14 秒 | 0.41〜6.60 秒 |
| 聞こえる大きさ | -19.3〜-9.6 LUFS（モノラル換算）。叫び声ほど大きい | -18.3〜-17.0 LUFS |
| ピーク | -1.5 dBTP 前後 | -1.0 dBTP 以下 |

- **モノラル**にした。左右がほぼ同じ（相関 0.9999 以上）だったので
- **無音**は、声の出だしの 30ms 手前から、終わりの 150ms 後ろまでを残した。
  頭 5ms・お尻 60ms でフェード。切り捨てた部分でいちばん大きい音は -46dB
  （息やノイズ。声の山より 45dB 下）で、声は削っていない。
  09「したへまいりまーす」は14秒あったが、うち12秒が後ろの無音だった
- **音量**は聞こえる大きさ（ITU-R BS.1770）で -17 LUFS（モノラル。ステレオ換算で約 -14）に
  そろえた。既存のためジャンプの声 `jump_voice.mp3` は -12.2、ゴール音 `goal1.mp3` は
  -12.8（ステレオ）なので、それより少し控えめ。叫び声（06 など）は下がり、
  小さい声（01「とぉ」など）は上がった。26「ええええ？」だけは上げるとピークが
  -1dBTP を超えるので、超えない所で止めた（-18.3）
- 1本ごとの数字は `resources/sound/voice/_report.tsv`
- 元の wav のフォルダには `.gdignore` を置いた。Godot に読み込ませると、
  34MB がそのまま書き出し（エクスポート）にも入ってしまうため。ファイルは残っている

案の「0.5〜1.5秒」を超えるものは無音を詰めても30本残る（長いもので 17 が6.6秒、
39 が6.1秒、38 が4.7秒）。セリフそのものが長いので、プレイ中に頻繁に鳴らす場面には
短いものを当てる。

## 実装（2026-11-25）

プレイ中のボイスを入れた。2秒を超える長いセリフはプレイの邪魔になるので入れず、
イベント（カットシーン）用に残してある。

### 仕組み

| | ファイル | |
| --- | --- | --- |
| 鳴らす係 | `scripts/voice.gd`（`Voice`） | Main が1つ置く。どこからでも `Voice.say(&"fall")` |
| 割り当て表 | `resources/voice_bank_ob.tres`（`VoiceBank`） | 場面ごとに声・確率・間隔・強さ。**エディタで開いて直せる** |
| 場面1つぶん | `scripts/voice_set.gd`（`VoiceSet`） | |
| 音量 | `VOICE` バス（`default_bus_layout.tres`）、OPTIONS の **VOICE VOLUME** | 既定 0.8 |

決まりごとは「設計の前提」のとおり。

- **声は重ねない。** 鳴っている最中に来たら、強さ（`priority`）が上なら上書き、
  そうでなければ鳴らさない。復帰だけは捨てずに、叫びが鳴り終わるのを待って続ける
  （`wait_turn`）。「どわー！」→「あれれー？」のように繋がる
- **直前と同じ声は選ばない**（その場面に1本しか無いときは除く）
- **確率と間隔**で聞き飽きないようにする
- 落下からの復帰中はツリーが止まるが、ボイスの係は止まらない（叫びが暗転で途切れない）

## イベントの声（2026-11-25）

長いセリフも含めて、イベント（カットシーン）のコマに声を入れた。

### 仕組み

- `CutsceneLine` に **`voice`**（そのコマで鳴らす声）を足した。CutsceneEditor の
  「声」で選べる（候補は `resources/sound/voice`）
- 声は VOICE バスで鳴る（OPTIONS の VOICE VOLUME が効く）
- 声を入れたコマでは、文字送りの「しゃべっているふうの音」は鳴らさない。
  前のコマの音が尾を引いていても切る
- 次のコマへ送ると止まる。Enter でイベントを飛ばしたときも止まる
- `tools/make_cutscenes.gd`（台本からの再生成）は、ほかの演出と同じく声も引き継ぐ

まとめて入れ直すときは次を流す（表を直して流し直せる。何度流しても同じ）。

```
python tools/assign_event_voices.py
```

コマは「話者と本文」で探すので、CutsceneEditor でコマを挿したり分けたりしてもずれない。
.tres はテキストのまま、声の行と ext_resource を足すだけにしている
（Godot で保存し直すと、ほかの参照から uid が外れて差分が大きくなるため）。

**台本の本文と声のセリフは同じではない。** 声は「そのコマの気持ちに合う反応」として
選んだ。台本が正なので本文は変えていない。字幕と声を揃えたいコマがあれば、
台本側を直すか、声を外す。

## ボイスの量（OPTIONS の VOICE）（2026-11-25）

OPTIONS に **VOICE: CHATTY / NORMAL / OFF** を足した。既定は CHATTY。
`Settings.voice_mode` に保存する（`settings_v2.cfg` の `audio/voice_mode`）。

| | プレイ中の声 | イベントの声 |
| --- | --- | --- |
| CHATTY（たくさん） | 割り当て表のとおり全部 | 鳴る |
| NORMAL（ふつう） | 節目だけ。何度も起きる場面はほぼ黙る | 鳴る |
| OFF（オフ） | 鳴らさない | 鳴らさず、文字送りの「しゃべっているふうの音」に戻す |

VOICE VOLUME を 0 にするのとの違い: 0 だとイベントの声のコマが無音になる
（声のあるコマは文字送りの音を止めているため）。OFF なら文字送りの音が鳴る。

### NORMAL の値

割り当て表（`voice_bank_ob.tres`）の各場面にある `normal_chance` / `normal_cooldown`
で決める（-1 なら CHATTY と同じ）。声の候補は1か所のままなので、声を足すときに
2か所直す必要はない。

| 場面 | CHATTY | NORMAL |
| --- | --- | --- |
| ためジャンプ | 30%・2秒 | なし |
| スーパージャンプ | 毎回 | 毎回 |
| 場外に落ちた | 毎回 | 25%・20秒あける |
| 熱い板 | 毎回 | 40%・20秒あける |
| 復帰したあと | 35%・8秒 | なし |
| 壁で滑る | 60%・6秒 | なし |
| ステージ開始 | 50% | なし |
| 復帰地点 | 70% | なし |
| ゴール／記憶／記憶がそろった | 毎回 | 毎回 |
| チュートリアル始まり／終わり | 毎回 | 毎回 |

### 確かめたこと（各場面 200 回ずつ鳴らして数えた）

- CHATTY: ためジャンプ 33%、落下 100%、復帰 41%、壁ずり 62% など設定どおり
- NORMAL: ためジャンプ・復帰・壁ずり・開始・復帰地点 0%、落下 26%、熱い板 42%、
  ゴールと記憶 100%。落下を鳴らしたあとは 20 秒あく
- OFF: 全部 0%
- イベント（stage04_outro「田中は誰やねん」）: CHATTY では声、OFF では文字送りの音
- OPTIONS の3択を押すと設定が変わる。選んでいるものは黄色の文字になる
