# ボイスリスト案

OB（および一部カニエナガ）の短いボイスを、プレイ中とイベントに入れるための案。

> **この案の範囲**
> ここで扱うのは「掛け声・リアクション」の**システムボイス**だけです。
> 台本のセリフ全部に声を当てる**フルボイス**は、本数が二桁変わる（v4台本で 500 行超）
> 別の判断になるので、ここには含めていません。
>
> 現状、会話中に鳴っているのは `voice.mp3` を話者ごとにピッチを変えて鳴らしている
> 「しゃべっているふうの音」で、実際の声ではありません（`Cutscene._speak()`）。

---

## 設計の前提

### 1. 鳴る頻度で優先度が決まる

このゲームは**地面に着くたび自動で跳ねます**。バウンドは1ステージで数百回起きるので、
そこに声を入れると確実に飽きます。**声は「めったに起きないこと」に付けるのが原則**です。

| 頻度 | 例 | 声を入れるか |
|---|---|---|
| 毎秒 | バウンド、着地 | **入れない**（今の効果音のまま） |
| 数秒に1回 | ためジャンプ | **確率で**鳴らす（20〜30%） |
| 数十秒に1回 | 落下、復帰、壁ずり | 入れる |
| ステージに数回 | 復帰地点、ゴール | 入れる |
| ゲームに1回 | 記憶取得、全クリア | 入れる（ここは贅沢に） |

### 2. 同じ声を連続で鳴らさない

同カテゴリ内はランダム選択。**直前に鳴ったものは次に選ばない**こと。
2本しかないと交互に聞こえて逆に目立つので、**最低3本**から。

### 3. 声同士を重ねない

1本のプレイヤーで鳴らし、再生中の要求は捨てるか上書きする。
効果音（着地音など）とは別プレイヤーにして、効果音は普通に重ねます。

### 4. 音量を別に出す

今の OPTIONS は BGM と SE の2つだけです。**ボイスは独立したバス**にして
スライダーを足すのをおすすめします（`default_bus_layout.tres` に `VOICE` を追加）。
「声だけ切りたい」「声だけ上げたい」は実況者向けタイトルでは要望が出やすい項目です。

## C. カニエナガ — 相棒の合いの手

OB だけだと独り言が続くので、**たまに相棒が挟まる**と画面が賑やかになります。
本数は少なくて構いません。**計 9 本**。

| ID | きっかけ | 本数 | セリフ案 |
|---|---|---|---|
| `kani_fall_` | 落下死（OBの声と**重ねず**、どちらか一方を確率で） | 4 | 「あーあ」「なにしとんねん」「へたくそ」「大丈夫かいな」 |
| `kani_goal_` | ゴール | 3 | 「やるやんけ」「ほんまに取りよった」「次いくで」 |
| `kani_memory_` | 記憶取得 | 2 | 「それがお前の大事なもんや」「ひとつ思い出したな」 |

落下時は **OBとカニエナガのどちらか一方**を鳴らします（50/50 など）。
両方鳴らすと台詞が潰し合って、どちらも聞き取れません。

## D. 見送り（入れないほうがよいもの）

| 候補 | 理由 |
|---|---|
| 通常バウンド・着地 | 頻度が高すぎます。数百回鳴ります |
| ため開始 | ためは 0.15 秒で満タンになります。開始と発射で二重に鳴ります |
| 傾けたとき | 常時入力なので鳴りっぱなしになります |
| ポーズ／メニュー操作 | 操作のたびに鳴ると煩わしく、スキップもできません |

## 収録の実務

### ファイル名と置き場

```
resources/sound/voice/
  ob_jump_01.mp3 〜 ob_jump_06.mp3
  ob_fall_01.mp3 〜 ob_fall_05.mp3
  ...
  kani_fall_01.mp3 〜
```

連番は**ゼロ詰め2桁**。コードは「接頭辞で始まるファイルを全部読んでランダムに選ぶ」
作りにすれば、**本数を増やすときにコードを触らずに済みます**（背景やポップアップの
読み込みと同じやり方です）。

### 収録時の注意

- **頭の無音を詰める**こと。`voice.mp3` は先頭 0.10 秒が無音で、そのままでは
  遅れて聞こえるため `voice_start` で飛ばしています。同じ手当てを増やしたくありません
- 尺は**0.5〜1.5 秒**。ゴールと全クリアだけは 2 秒まで
- 落下の声は**短く**。復帰演出が 0.5 秒なので、それより長いと次の場面に食い込みます
- テンションは「配信中のノリ」。素面のときより一段高め、ただし酔ってはいない
  （酔っているのは OP だけです）

### 本数のまとめ

| | 本数 |
|---|---|
| A. プレイ中（最小構成） | 27 |
| B. 演出の節目 | 10 |
| C. カニエナガ | 9 |
| **合計** | **46** |

A だけで 27 本。まず A を録って入れてみて、物足りないところに B・C を足す進め方を
おすすめします。

## 実装側で先に要るもの

ボイスを入れる前に、コード側でこの3つが必要です。

1. **ボイス再生の共通化** — 接頭辞でまとめて読み、直前と同じものを選ばず、
   再生中は重ねない。`Cutscene._speak()` の最短間隔の考え方がそのまま流用できます
2. **`VOICE` バスと OPTIONS のスライダー** — `default_bus_layout.tres` と
   `scripts/settings.gd` / `scripts/title.gd`
3. **復帰地点のシグナル** — `Game._update_checkpoint()` は今 `print` だけで、
   外から拾えません

どれも小さいので、収録前にこちらで用意できます。
