━━━━━━━━━━━━━━━━━━━━━━━━
０．共通演出フォーマット
━━━━━━━━━━━━━━━━━━━━━━━━

全10ステージで同じ型を繰り返すことで、視聴者が「今どのパートか」を
迷わず把握できるようにする。

【幕間・開始】の型
  1. ステージタイトルカード（STAGE X）
  2. カニエナガが肩から飛び降り、正面に着地
     → 立ち位置が変わることで「説明モード」だと一目で分かる
  3. ヒントパネルが1行ずつ出現（SE：ピコン）
  4. OBの誤答 → 誤答イメージがカットイン → ヒビが入って割れる（SE：ブッブー）
     ※ST6・ST7・ST10は誤答が無いので手順4を飛ばす（詳細は§4）
  5. カニエナガのツッコミ → 画面が横に揺れる
  6. 「GO!」でステージ開始

【幕間・ゴール後】の型
  1. アイテムがシルエットで宙に浮かぶ
  2. OBが触れる → 光が弾けてシルエットが本体に変化（SE：ジャラーン）
  3. アイテム名テロップが下から出る
  4. OBのリアクション（表情差分の見せ場）
  5. 「記憶を1つ取り戻した」
  6. 記憶コレクション画面に追加され、カウンタが X/10 に増える

※この「シルエット→本体」の演出が、今回の構成（ヒントで引っぱって
  ゴールで初めて中身を知る）と噛み合う。ヒント中は常にシルエットを
  画面端に小さく置いておくと、視聴者も一緒にクイズに参加できる。

■ オープニング
  必要素材：BG-01, BG-02, OB-02(泥酔), OB-03(激痛), ITEM-02
  演出：
   1. 暗転から自宅リビング。OBふらふら歩き（泥酔差分）
   2. 冷蔵庫の扉が開く → 庫内の光がOBを照らす
   3. ビール缶アップ → プシュッ（SE）
   4. 廊下へ。カメラをOBの足元へ寄せる（タンスの角を予告）
   5. ゴンッ！ 画面を白にフラッシュ＋激痛差分
   6. ホワイトアウトのまま異世界へ繋ぐ（暗転ではなく白で繋ぐ）

■ 転生直後
  必要素材：BG-04, OB-04(困惑), カニエナガ01/02
  演出：
   1. 白からフェードイン。OBの主観で空を見上げる → 巨大な月
   2. カメラが引いて石畳の広場と塔
   3. 肩のカニエナガがアップ（ここで初めて喋る＝顔の寄り必須）
   4. ヒント形式のルール説明（「中身は言わん」）で
      UI-02のヒントパネルを空の状態で1度見せておく
      → この後10回使う枠を先に印象づける
   5. UI-05の記憶コレクション画面を全シルエットで初お披露目

■ STAGE 1 ～ 9（共通の型＋固有演出）

  ST1 風の林
    素材：BG-05, ITEM-01, MISS-01, OB-06
    固有：ラベルに寄るカット必須（OBが読み上げるため）
          「体が震える」で画面を小刻みに振動
          締めの「飲んでいい？」→「飲むな！」は
          POP-35が不採用のため、OB-01とカニエナガ03の掛け合いだけで処理する

  ST2 ハイパードライ
    素材：BG-06, ITEM-02, MISS-02, OB-06
    固有：開栓を「音先行」で。暗転 → カシュッ → 画面が開く
          泡のパーティクル。よだれ差分アップ
          締めの「飲むしか無いよね」はPOP-36が不採用のため、
          立ち絵とSE（ゴクゴク）だけで処理する。
          ST1で止めてST2で押し切る対の構造は台詞側には残っている

  ST3 カニ
    素材：BG-07, ITEM-03, OB-06/OB-07, カニエナガ03
    固有：ヒント「赤い・足が多い・殻がある」でカニエナガに
          スポットが当たる（OBの勘違いを絵で見せる）→「ワイちゃうわ！」
          食事シーンは長回しの無音。BGMを完全に切ると笑いが立つ
          食べ終わりで殻の山にカット

  ST4 レッドアイ田中
    素材：BG-08, ITEM-04, MISS-04, OB-01
    固有：OBが弦を弾く手元アップ＋実際にウクレレのSE
          「田中」の名札に寄る → 間 → 「田中は誰やねん」

  ST5 オバーレン
    素材：BG-09, ITEM-05, MISS-05, OB-09(むふー)
    固有：表紙アップ。「似た名前の漫画」のくだりで
          OBが首をかしげる → カニエナガが目をそらす
          「もう読んどる！」でOBが座り込んで読みふけっている絵
          ラストの「本当にゲームの世界に転生したんだ……」は
          POP-37が不採用のため、OB-05（驚き）＋間で処理する

  ST6 ファイナルファンタジア6
    素材：BG-10, ITEM-06, OB-05, OB-12
    固有：ヒント「ふーふー吹く」でカセット端子のアップ
          回想として配信画面（コメントが流れる）を重ねる
          「帰りたい」で初めてBGMを止め、表情を12(寂しげ)に
          ※ここが中盤の折り返し。唯一しんみりさせるステージ

  ST7 宝箱
    素材：BG-11, ITEM-07(3差分), ミミック01-03, OB-09/OB-10/OB-13(任意)
    固有：開ける直前に一拍ためる
          噛みつきは画面を真っ暗に → 口内カットへ
          口内は視界を丸く狭めた演出（OBの主観）
          ノドチンコに変なスポットライト
          締めの「やめられまへんなー」はOB-13。無い場合はOB-09で代用可
          ※ミミックは「ガブガブ」と発話する＝話者として扱う。
            台詞表示を使う構成なら名前表示の用意も要る

  ST8 現金
    素材：BG-12, ITEM-08, MISS-06, OB-08(＄目)
    固有：ヒント途中でOBが気づく → カニエナガが口を塞ごうとする
          ＄目差分でストップモーション＋効果音
          ゴール後の「どんな回り道でもするわ」はOB-08のまま押し切る（新規素材なし）

  ST9 天城越え
    素材：BG-13, ITEM-09, MISS-07, OB-11(ドヤ顔)
    固有：ヒント「山を越える歌」で背景の山を指差す
          「山、越えられるかな？　ちょっと心配」はOB-01に汗を足して流用
          ゴールで本当に山頂に立っている絵（歌＝登山のボケを絵で確定させる）
          ラスト、カニエナガが答えない箇所は
          カニエナガ04(沈黙)＋BGMフェードアウト＋風の音だけ

■ STAGE 10 カニエナガ
  素材：BG-04(広場に戻る), BG-14(ゲート), カニエナガ04/05/06,
        OB-05, OB-12, シマエナガ
  演出：
   1. 幕間は最初の広場。ただし月の位置が変わっている（時間経過の表現）
   2. カニエナガは基本ずっと背中を向けたまま喋る。
      ただし幕間ラストの「一緒に行こう！」→「当たり前や！」で
      一度だけ振り返る。ここだけ表情05（優しい笑み）
   3. ヒントパネルは1行だけ。他ステージが3行なので落差が出る
   4. ゴール：10個目のシルエットが浮かぶ
      → 形が「肩に乗っているカニエナガ」と同じだとOBが気づく
      → ここでカメラがOBの肩と光を往復する（気づきを絵で見せる）
   5. 光が晴れて本体に。カニエナガ06
   6. UI-05が10/10で全点灯 → 光のゲートが開く
   7. 「なんか帰りたくなくなってきちゃった」でOB-12。
      ここはBGMを止めて間を取る（v4で増えた本音の箇所）
   8. 「こっちのカニエナガも一緒に行けない？」→ 双方「………」。
      カニエナガ04(沈黙)。台詞を入れず、間だけで見せる
   9. 別れはカニエナガ05(優しい笑み)。ただし最後の一言
      「もう小指ぶつけるなよ」で再び04(沈黙・顔に影)に戻す
      → 直後のEDで実際にぶつけるので、ここが振りになる
      ※回想カット（POP-38）は不採用。台詞だけで振りを成立させる

■ エンディング
  素材：BG-03, シマエナガ, OB-04, OB-12, OB-03, オビラーたち
        ※v4ではベッドから立ち上がった直後にぶつけるため、
          場所は寝室内。BG-02(廊下)は不要になった。
          POP-33は寄りの絵なので背景の影響は受けない
  演出：
   1. 光に包まれる → ホワイトアウト（OPと同じ白で繋ぐ＝対になる）
   2. ベッドで目覚め。肩にシマエナガ
   3. 「チュン」→ ここでカニエナガの声が返ってこない“間”を長めに取る
   4. 寂しげな笑み
   5. 立ち上がる → ゴンッ！ → 暗転（今度は白ではなく黒）
   6. 暗転のまま音声だけで「もう二度とお酒飲まない……」
   7. 間 → 「いや、飲むわ」
   8. オビラーたちのコメントが画面を埋め尽くす
   9. THE END

  【検証方法】
